# «Голдфиш» — лендинг

Одностраничный сайт производителя рыбы холодного копчения. Реализация
вайрфрейма 1a (Editorial vertical) из пакета `design_handoff_severny_ulov_landing`
(бренд позже переименован в «Голдфиш», исходный хендофф так и назывался).

## Стек

- **Astro 5** со статической генерацией — весь сайт собирается в статику.
- Ноль фреймворков на клиенте: поведение написано на TypeScript, в бандл уходит
  ~2.7 kB (gzip).
- CSS — токены + scoped-стили компонентов. Ни Tailwind, ни UI-библиотек.

### Почему Astro 5, а не 6/7

Astro 6 требует Node ≥ 20.19, Astro 7 — Node ≥ 22.12. На машине сборки Node
20.17, поэтому зафиксирована ветка 5.x. `npm audit` показывает на ней XSS-адвизори
Astro; все они касаются `define:vars`, spread-пропсов, view transitions, server
islands и slot-имён — ничего из этого в проекте не используется, а сайт полностью
статический. **Рекомендация:** обновить Node до 22 LTS и поднять Astro до 7 — это
закроет адвизори без изменений в коде.

## Структура

```
src/
  data/            весь контент в одном месте
    site.ts        навигация, контакты, соцсети, мета
    content.ts     тексты секций, ассортимент, шаги, галерея
  components/      секции лендинга + Photo, Logo, Icon
  layouts/         BaseLayout — head, шрифты, мета
  scripts/         поведение: header, parallax, reveal
  styles/
    tokens.css     ЕДИНСТВЕННОЕ место, где живёт палитра и типографика
    global.css     сброс, раскладка, кнопки, поля, фото
public/images/     сюда кладутся реальные фотографии
```

Ассортимент и блоки «почему» описаны данными — карточки рендерятся циклом,
разметка не дублируется.

Формы заявки на сайте нет: сбор персональных данных через веб-форму требует
регистрации оператора персональных данных и соответствия 152-ФЗ, это решили не
делать. Вся коммуникация — через контакты в разделе «Контакты» (телефон,
мессенджеры, email).

## Что осталось от заказчика

Это блокирует запуск. До получения — на странице видны честные заглушки,
а не выдуманные значения.

| Что | Где подставляется |
| --- | --- |
| Телефон, мессенджеры, адрес, режим работы | `src/data/site.ts` → `contacts` |
| Ссылки Telegram / WhatsApp / MAX (сейчас только номер текстом) | `src/data/site.ts` → `contacts` |
| Логотип (SVG на светлом и на тёмном) + фавикон | `src/components/Logo.astro` |
| Фотографии | `public/images/`, см. `CONTENT.md` |
| Вычитка текстов | `src/data/content.ts`, см. `CONTENT.md` |

### Как подставить фотографии

У каждого кадра в `src/data/content.ts` есть поле `photo` с `alt` и `spec`.
Достаточно добавить `src`:

```ts
photo: {
  src: '/images/forel.jpg',
  alt: 'Форель холодного копчения',
  spec: 'форель, кадр 4:3',
}
```

Пока `src` нет — рендерится заглушка с описанием нужного кадра. Пропорции
держит `aspect-ratio` на контейнере, поэтому вёрстка при подстановке не поедет.

## Отступления от хендоффа

Три штуки, каждое осознанное.

**1. Шрифт: `Golos Text` вместо `Archivo`.**
У Archivo на Google Fonts нет кириллического subset — проверено, отдаются только
`latin`, `latin-ext`, `vietnamese`. Весь русский текст уходил бы в системный
фолбэк, и типографика макета не работала бы вовсе. Golos Text — гротеск близкого
характера, спроектированный под кириллицу. Меняется в одну строку:
`--font-sans` в `src/styles/tokens.css`. Если у заказчика есть лицензия на
кириллическую версию Archivo — вернуть её и self-host'ить.

**Заголовки, kicker'ы и кнопки — `Unbounded` (`--font-display`).** Акцентный
шрифт поверх Golos Text: крупный, блочный, даёт бренду более дизайнерский
характер. Тоже с полной поддержкой кириллицы. Меняется в `--font-display` в
`src/styles/tokens.css`.

**2. Палитра: тёмно-синий + тёплый оранжево-красный.**
В вайрфрейме брендовых цветов не было (ink `#201e1d`, акцент только для
рукописных аннотаций). Взята ожидаемая палитра логотипа из хендоффа: ink стал
тёмно-синим `#12263d`, акцент — `#e5401b`. Всё через переменные в `tokens.css`,
перекраска под финальный логотип — одна правка.

**3. Кнопки «Узнать цену» ведут в «Контакты», а не на карточку вида рыбы.**
Страница вида рыбы в пакете не спроектирована. Карточка кликабельна целиком и
ведёт к разделу «Контакты» (телефон/мессенджеры/email — формы на сайте нет).
Когда появится макет карточки — поменять `href` в `src/data/content.ts` →
`products`.

## Открытые вопросы

- **Мобильная версия** (390 px) отдельным макетом не приходила. Сделана
  разумная адаптация по правилам из хендоффа: ниже 1024 витрина 3×2 → 2 колонки,
  «почему» 4 → 2, меню в бургер с полноэкранной панелью; ниже 700 — одна
  колонка, кнопки на всю ширину, высота ≥ 48 px. Композицию стоит подтвердить
  дизайном.
- **Страница политики обработки персональных данных** не спроектирована,
  ссылка в подвале временно ведёт к «Контактам».
- **og:image** — нужен кадр 1200×630 из фотосессии.
- **Шрифты** сейчас с Google Fonts. Перед продакшеном — self-host с подмножеством
  latin + cyrillic.

## Поведение

- Шапка sticky, при скролле > 80 px сжимается 88 → 64 px. Переход к якорям
  считает offset вручную с учётом того, что sticky-шапка остаётся в потоке и при
  сжатии утягивает контент вверх.
- Scroll-spy подсвечивает активный пункт меню.
- Parallax hero через `transform`, отключается при `prefers-reduced-motion`.
- Карточки и блоки плавно проявляются по скроллу (IntersectionObserver, шаг
  70 ms в пределах пачки, однократно, `[data-reveal]`).
- У всех интерактивных элементов свои hover / active / focus-visible состояния,
  дефолтные браузерные не оставлены.
